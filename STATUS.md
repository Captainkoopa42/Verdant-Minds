# Verdant-V0 Engineering Status

This file describes the code that is actually present on the `Verdant-V0` branch. It replaces earlier status text that mixed V0 with work from later branches.

## Executive assessment

Verdant-V0 is a runnable research prototype with a coherent central execution path and unusually extensive instrumentation for an early-generation architecture. The canonical runtime, test suite, real kernel demo, state persistence, cultivation runner, structural analysis, and paper materials are all present.

It is not a finished application or a self-contained distributable package. The repository also preserves duplicated source files and an incomplete later `verdant/` tree, which makes orientation harder unless the reader follows the documented entry point.

## Implemented architecture

- `CognitiveChunk` accumulates sections throughout one processing cycle.
- Nine blocks process each input in a fixed order.
- `MemoryWeb` stores concepts and weighted relationships.
- `ECWFCore` maintains cognitive and ethical wave-state dimensions.
- `MemoryECWFBridge` moves influence in both directions between graph and wave state.
- `ThreeKingsLayer` performs staged data, ethical, and executive oversight.
- Coherence invariants are calculated at cycle end and fed into the following cycle.
- Pickle and JSON state paths exist; JSON is used by the cultivation workflow.
- The cultivation runner records session, cycle, state, and significant-event artifacts.
- The scaffolding analysis script measures temporal orientation in an emergent-concept backbone.

## Important limitations

### Packaging

`pyproject.toml`, `setup.cfg`, and `setup.py` disagree on package metadata, and the built wheel contains `usm` but not `Verdant Source Codes`. A normal wheel installation therefore cannot carry the canonical runtime by itself. Use a source checkout and editable install for this branch.

### Source layout

The canonical modules exist in lower-case files, while several parallel upper-case files are also preserved. The runtime imports the lower-case modules. The top-level `verdant/` tree is a different, incomplete direction and must not be confused with the V0 entry point.

### Semantics and response generation

The system contains meaningful graph, wave, governance, state, and telemetry mechanics, but its built-in natural-language responses are templates. Optional external providers supply generated text during cultivation; that text is not generated by V0 alone.

### Optional semantic mapping

The Memory–ECWF bridge can use `sentence-transformers` and scikit-learn. When unavailable, it warns and falls back to a seeded/randomized concept-dimension mapping. Results from the two modes should be reported separately.

### Timing of `T_g`

`T_g` is updated near the beginning of a cycle, before that cycle has produced its memory and wave sections. It therefore uses sensory data plus existing or previous state, not all signals later generated in the same cycle.

### Research validation

Passing tests demonstrate implementation behavior, not scientific validity. The published scaffolding numbers are reported results from the included whitepaper. This documentation audit did not rerun the original cultivation experiment from scratch.

## Known warnings

The audited suite emitted 38 warnings from deprecated `datetime.utcnow()` usage in cultivation code. These did not fail the suite, but should be migrated to timezone-aware UTC timestamps in future code work.

## What belongs to later work

References to an extracted `ethomorphic/` package, a `verdant_v2/` pipeline, or their test counts describe another branch/state. They are not claims about the contents of `Verdant-V0`. The files under `verdant/` are retained here as evidence of direction, not as the runnable V0 system.

## Appropriate description

A defensible one-sentence description is:

> Verdant-V0 is a runnable, test-covered research implementation of a hybrid graph-memory and wave-state cognitive pipeline with staged governance, persistence, telemetry, and experimental analysis tooling.
