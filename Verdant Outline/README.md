## Evidence boundary

The source tree implements several named ideas: ECWF calculations, a graph memory, a memory/ECWF bridge, nine blocks, and Three Kings governance. That correspondence shows that the concepts influenced the software design.

It does not by itself verify the outline's claims of consciousness, AGI, emergence, quantum computation, ethical correctness, cross-domain superiority, or reported percentage improvements. In particular, the branch lacks the raw artifacts needed to reproduce claims such as `T_g ≈ 0.63`, `217%` greater solution diversity, `340%` greater connection formation, reported ethical consistency values, or 150-scenario evaluation.

Read those statements as hypotheses, historical reports, or aspirations unless a future evidence package supplies datasets, baselines, scripts, raw results, and analysis. See [../docs/reproducibility.md](../docs/reproducibility.md).
