## Critical Milestone 19 warning

`milestone_19_benchmark_summary.json` has schema `verdant.ethomorphism_benchmark.v1`. It was generated by the historical oracle-assisted formation path: evaluator ground truth selected P/Q promotion targets. It is not valid evidence of evaluator-independent selection.

The current source implements `verdant.ethomorphism_benchmark.v2_oracle_free`. Its revalidation is documented in [../MILESTONE_19_ORACLE_REVALIDATION.md](../MILESTONE_19_ORACLE_REVALIDATION.md), but a corrected raw result JSON is not currently tracked here.

Generate a current result without overwriting history:

```bash
python run_ethomorphism_benchmark.py \
  --output /tmp/verdant-v5-oracle-free.json \
  --seed 1901 \
  --state-dim 16 \
  --noise-concepts 16
```

## Safe use

- Verify `.vdk` files through `verdant_kernel.load_checkpoint()`.
- Match every artifact to its report and schema.
- Preserve historical outputs rather than silently regenerating them under changed code.
- Use a new directory or `/tmp` for audits and experiments.
- Record current build identities, dependency environment, seed, and complete command with any new result.

See [../docs/reproducibility.md](../docs/reproducibility.md) for the evidence hierarchy and current validation state.
