# CognitiveChunk v2 — typed multimodal plumbing

This package is the compatibility-oriented data-plane rebuild used by the independent Verdant project.

It preserves native payloads, immutable observations, modality translations, claims, contradictions, revisions, cognitive effects, lineage, permissions, archive integrity, and nine-block compatibility views.

It is plumbing, not a standalone cognitive architecture. The canonical Verdant kernel and language path live in sibling packages.
