# Verdant-Minds V4 — Colab Workflow

This directory contains the current Colab-facing workflow for the V4 submission branch.

## Quick Start

Use `V4_Colab_Workflow.md` for the ordered workflow, then paste or run the individual cells from `cells/` as needed.

## Cell Order

| Cell | Purpose |
|------|---------|
| 01 | Clone the repository |
| 02 | Create workspace symlink |
| 03 | Install packages |
| 04 | Run focused tests |
| 05 | Run experiments |
| 06 | Compare intervention runs |
| 07 | Print comparison summary |
| 08 | Bundle and download outputs |
| 09 | Scaffold analysis |
| 10 | Extract a previously downloaded bundle |

Legacy notebooks were moved under `archive/` and are outside the current V4 Colab workflow.
