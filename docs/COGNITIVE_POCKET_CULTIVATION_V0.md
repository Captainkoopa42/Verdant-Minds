# Cognitive Pocket Cultivation v0: bounded P/Q-mitosis research probe

Status: **implemented-experimental**, isolated in `test/cognitive-pocket-cultivation-v0` from the exact Obligation Substrate v0.67 commit `6aeb75841025`. V4 `verdant/memory/mitosis.py`, `verdant/memory/basin_dynamics.py` and `verdant/pipeline/basin_processor.py` were INSPECTED for design ideas; none of their old NetworkX writes, split/persist semantics, old daughter registry, threshold decisions, or incompatible memory formats is integrated into the current native V5 kernel.

## Scientific hypothesis

Given 2–8 actually Council-promoted, currently available native P memories, a bounded pocket could preserve heterogeneous typed relation evidence while exhibiting local interaction and surfacing non-factual role correspondence proposals. This is an **early, reproducible substrate test**; it does NOT demonstrate a newly synthesized semantic object, cognition, autonomous binding discovery, learned ontology, compression, independence of memory compartments, or endogenous inquiry.

The original 12-P/2-Q seed-81001 60-experience study is the intended next read-only audit input. Its 12 P clusters contain disjoint concept memberships: two Qs group Ps, but Q membership does not create cross-P concept-level canonical relations. Do not treat expected topology alignments as factual connections.

## Exact v0 boundary

1. Select 2–8 genuinely promoted available native P records, optionally requiring that all are actual members of one available Council-promoted native Q. The Q is **context**, not a truth gate or synonym dictionary.
2. Copy the P constituent concept IDs, exact promotion evidence refs, promotion-time plastic association snapshots, and all *CURRENT* native canonical typed relations whose endpoints lie within each member set. This separates relation snapshots at current inspection time from their possible absence at P promotion. Missing current evidence links fail closed.
3. Compute a concept-name and relation-name-renaming invariant **relational grammar signature**, encoding directed endpoints and the equality pattern of relation types (R,R versus R,S). Preserve complete native relation IDs, type strings, directions, status and evidence. This is an index, not an ontology. No measured physical or binary compression is claimed.
4. Inspect topology-only analogy candidates with the unchanged native `VerdantStructureInteractionPipeline._symbolic_alignment`. If above the explicit threshold, retain a one-to-one role mapping as `hypothetical_role_correspondence`. Neither an asserted same-object identity nor semantic relation is created. This channel has no evidential authority.
5. Reconstruct *existing* native canonical relations crossing actual P member regions separately as `evidenced_cross_p_relations`. An explicit source-checked canonical relation, not Q membership or an analogy, is required. Compose only exact, direction-respecting two-edge canonical path DESCRIPTIONS across such a relation; path composition does not imply logical transitivity or a new canonical conclusion. Historical curricula without cross relations should yield zero such paths; that is a valid negative observation.
6. Run 1–12 numeric private activity rounds with separate documented channels: historical native plastic snapshots, existing directed canonical cross-P edges, hypothetical role-map coactivation. The latter is always identified as simulation-only; it never writes truth, Q, P, canonical edges, obligations or simulated Resolution.
7. Return a deterministic in-memory report with source checkpoint fingerprint, P evidence, candidate alignments, per-round activation, canonical cross-paths, and a typed-grammar inventory. The CLI writes one exclusive-create JSON sidecar, keeps source VDK unchanged and prints counts.

## Integration with Obligation Substrate

This stage deliberately DOES NOT instantiate `DependencyGapObligationKernel`, request Attention, reserve a CounterfactualRuntime settlement, auto-promote a compressed pocket, or modify Council state. Doing so without family-specific grounding and a source-locked matched control would misrepresent an analogy as an obligation. A later increment should use genuine unresolved typed canonical dependencies as handoff triggers; a proposed role match alone is not that evidence.

## Tests and required ablations

- Real native Council-earned P/Q fixture from `test_hierarchy_phase.py`; no fabricated P/Q objects.
- Current canonical typed relation records added by EXPLICIT TEST-HARNESS TESTIMONY *after* P promotion; this is not independent learning evidence.
- Three differently typed member relation families stay separate while topology offers hypothetical mappings.
- Local numeric activity and hypothetical correspondence can occur with ZERO canonical cross-P relation.
- An explicitly harness-supplied native cross-P relation enables a reconstructable two-hop path description; matched no-bridge control cannot produce it.
- Exact replay across cloned snapshots, P-input order invariance, original VDK byte immutability.
- Invalid IDs, foreign Q membership, duplicate P, out-of-bounds rounds, absent evidence refs reject.
- No native policy, promotion, Council, obligation, or repository legacy record rewritten.

## Falsification / next dependency

Try this on both of the real twelve-P checkpoint's Qs. Report number of *native* cross-P relations/path compositions separately from hypothetical analogies. For this original disjoint corpus, don't reinterpret the presence of many mappings, grammar groups or coactivation as grounded cross-domain conclusions.

Next increment after this bounded pilot: **controlled, opt-in pocket persistence and evidence-grounded interaction protocol** with explicit no-link, random-link, wrong-link, reversed-direction and exact-null arms. Use held-out evidence with a frozen answer-independent evaluator. Only after that should any richer local dynamics, native Obligation attention, true structural compression/reconstruction-cost claims, or cross-pocket writeback be contemplated. Do not reuse V4 `mitosis.py` writes against V5 VDK.

The P/Q brain-building hypothesis is still open: Can memories interact in a pocket to produce justified new *compositional* capabilities, rather than just new counts or structural correspondences? This v0 provides an inspectable and safe mechanism to test that question, but is not yet a positive result.
