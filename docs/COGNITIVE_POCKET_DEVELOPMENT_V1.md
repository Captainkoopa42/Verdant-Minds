# Native Cognitive Pocket Development v1 — isolated complete experimental lifecycle

Branch: `test/cognitive-pocket-cultivation-v0`. Base: `test/obligation-substrate-v0` v0.67 commit `6aeb758`. This is an **experimental implementation**, not an integrated V5 canonical engine capability, an autonomous mind, or verified semantic understanding.

## Actual completed operations

1. Load **genuine native** available Council-promoted P sources, optionally within a promoted Q, from an unchanged VDK. Export their current exact canonical typed relations, directions, statuses and evidence refs alongside promotion-time plastic snapshots.
2. Start **localized** stimulation in exactly one P, not all P simultaneously. Run eight matched deterministic simulation arms: `null`, `native_only`, `role_aligned`, `role_scrambled`, `same_grammar_only`, `canonical_only`, `canonical_reversed`, `combined`.
3. Cross-structure topology correspondence is **hypothetical only**. Compatible relation-variable grammar (e.g. R-R) permits bounded role activity (weight coefficient 0.22). Different variable grammar (R-S) permits weaker, separately labeled **heterogeneous exploratory activity** (0.08). Unlike native exact typed relationships, neither correspondence is a canonical truth claim.
4. Native `SUPPORTED` or `CONFIRMED` typed cross-P relations, if any, receive a separately labeled evidence-backed channel. Neither `HYPOTHESIS`, `REJECTED`, nor `CONTRADICTED` native records qualify. Reverse-direction control tests directional sensitivity. A two-edge native path is NOT assumed to be logically transitive.
5. Persist exact per-round activity and transfer attempts with local parent/daughter provenance. Each matched arm has identical source, initial energy, and duration; reported difference is L1 of numeric activation versus its native-only matched control. An effect is not semantic progress.
6. Partition P into read-only **experimental daughter pockets by observed relational grammar**, preserving every source P and concept exactly once, plus inter-daughter boundary pointers. These are candidate daughter partitions, NOT V4 `mitosis.py` filesystem splits and not independent native agents.
7. Apply bounded isolated Hebbian-like **local plasticity** across repeated sessions. A last P is excluded from training **stimulus presentations**, then probed with adapted weights versus a frozen original-weight control. This is not a held-out semantic outcome, new world observation, or learning certification.
8. Emit an exactly checked dictionary-coded copy of current native typed relation records with all directions, predicate names, evidence IDs, and status markers recoverable. Measure actual bytes before/after; a negative reduction means the dictionary increased storage. Also measure zlib compression on a canonical JSON archive. Neither constitutes learned ontological abstraction.
9. Inspect native `DependencyGapDetector.inspect()` for **real canonical `requires` edges** in the source pocket. Report only actual verified detector candidates; never record, advance, schedule, resolve, or mutate obligations from role analogy.
10. Seal each lifecycle in an exclusive-create **.vcpl** sidecar, with deterministic record hashes and replay checks. The original VDK and all canonical P/Q relations, approvals, obligations, and event ledgers remain unchanged. Export an optional completely offline SVG/HTML visual replay.

## End-to-end data boundary

`original.vdk` (read only)
→ `cultivate_pocket()` (native P/Q checked)
→ `paired_cohort()` (matched numeric controls)
→ `daughter_partitions()` (metadata-only, lossless split)
→ `local_cultivation()` (private bounded plasticity)
→ `pack_native_relations()` (exact evidence-preserving dictionary)
→ `compression_receipt()` (zlib exact replay)
→ sealed `lifecycle.vcpl` (no VDK write)
→ `viewer.py` (offline observation)

The exact native obligation handoff runs at the source kernel layer in `lifecycle_cli.py` and is disclosed in the command's JSON summary. No native write authority crosses the pocket boundary.

## Essential negative controls and red lines

- Native-only should keep separate canonical islands isolated when there are no actual native bridges.
- Role-aligned can transfer numeric activity into other P regions, but must be compared with role-scrambled, same-grammar-only, and null controls. Do NOT infer usefulness from increased activations alone.
- Distinct typed relationships remain preserved, including unlike predicates and direction; no same-sounding role is silently treated as semantic identity.
- Exact missing evidence, forged role endpoints, duplicate P IDs, absent Q membership, nonfinite weights, out-of-budget runs, invalid direction, mismatched source fingerprint, mutated daughter pointers, tampered history and occupied outputs fail closed.
- Local plasticity may merely reinforce accidental associations. A numeric held-out effect does not establish useful semantic generalization.
- Compressed dictionaries and zlib archives must reconstruct every recorded typed relation and evidence ID. Lossy abstraction is not authorized.
- A detached immutable sidecar is **not** committed to the canonical VDK. No unattended worker, background scheduler, cross-thread locking, durable append between invocations, physical operating-system sandbox, or experimental child execution loop is provided.

## Verification

GitHub's manual research workflow checks the native Council P/Q tests, original pocket tests, new lifecycle, integration, obligation and counterfactual regressions. Focused verification and the full native test suite should both pass before proposing any upstream use. The branch retains old milestones separately.

The original seed-81001 Section-3 VDK's 12 Ps and 2 Qs remain the baseline. Because Q membership does not introduce native cross-P semantic edges, a zero canonical cross-P path count is expected. Positive **hypothetical numeric activity** is a mechanism check, not an earned new concept.

## Needed before canonical writeback or a true developmental mitosis engine

A future v2 would need explicit evidence-backed cross-P *candidate proposition* formation, independent ground-truth outcomes/held-out question answering, family-specific Obligation authority, reward or resolution criteria that cannot be gamed by raising activation, genuinely durable child-specific learning state and merge conflict rules, compression-before/after task comparisons, controls for random/scrambled/no links and relation-type reversals, and checkpoint-compatibility testing across all supported native histories.

The v1 system is built to expose these missing dependencies cleanly rather than assume or fake them.
