# Cognitive Pocket v2 — Selective, evidenced relational composition

Status: **implemented, experimental; native source read-only**. Research branch: test/cognitive-pocket-selective-composition-v2, branched from Cognitive Pocket v1 commit 5182bbf. Parent P/Q, Obligation Substrate v0.67, and original native 336-cycle memory are unchanged.

## Scientific question

Can genuine Council-promoted P structures support an independently checkable relational conclusion spanning 2+ P memories through actual direction-correct canonical evidence, while abstaining on wrong or missing evidence and unrelated structural analogies?

**This is a rule-following composition milestone, NOT independently learned semantics, world observations, autonomous hypothesis invention, or persistence of a learned reasoning method.**

## Mechanics

- A CompositionQuery supplies only source ID, target ID, exact relation predicate, and bounded search budgets. Target identity is a legitimate question endpoint, not a supplied true answer. The final composite relation is never preinserted.
- Only SUPPORTED/CONFIRMED, directed, exact same-type canonical relations can witness a conclusion. Source relation IDs and evidence references are preserved. The external policy explicitly licenses transitivity only for PRECEDES. Supports, contains, requires, bounded_by and other predicates are never assumed transitive merely from their spelling or topology.
- P-level routing sees canonical cross-P edges to select genuine native Ps. Within candidate routes a bounded directed BFS searches exactly typed relations, limiting members, routes, hops and work. Q membership, native plastic association, and hypothetical topology analogies cannot establish facts.
- Accepted witnesses identify every original relation and source evidence. The composite remains an experimental derived-rule consequence: no native claim, Q/P promotion, obligation resolution or writeback.
- Wrong direction, missing bridge, wrong predicate, missing relevant P, contested evidence, unknown relation grammar and resource exhaustion yield explicit abstention, NOT a claim of falsity.
- External grading is accessed only after all queries have already been executed. The frozen task set records true/false positives and negatives; activation and arbitrary links earn no credit.

## Matched control arms

The control helper evaluates copy-only synthetic views with identical queries and budgets:
1. Actual canonical native cross-P witness (main)
2. Remove every cross-P relation
3. Reverse every directed cross-P bridge
4. Replace cross-P bridge predicate
5. Restrict to unrelated genuine P members
6. Modify only hypothetical role mapping metadata

Changing analogical mappings must NOT change a canonical witness. Reverse and missing bridging conditions should yield abstention. These are synthetic counterfactuals in copies, not changes to VDKs.

## Positive and negative source conditions

- **Disposable teacher-staged native demo**: Three genuine promoted P structures and a genuine Council-promoted Q. Teacher supplies individual primitive typed relation testimony to each P. A separate teacher-supplied cross-P relation r4 PRECEDES s1 is provided, but **never** the requested r1 PRECEDES s4 conclusion. Predicate transitivity is declared by experiment policy. Unrelated t-P has SUPPORTS links. Six frozen questions include correct, reversed, unrelated-P and unlicensed relation controls. Any positive result demonstrates bounded declared-rule execution, not spontaneous rule discovery.
- **Original 336-cycle real checkpoint**: Native read-only, no teacher bridges. Its two Qs group 4 P and 8 P; no canonical cross-P edges were demonstrated in the original recordings. Across-P questions must abstain. This is a negative control, not a failed positive condition.
- **Native controlled fixture**: Genuine Council-promoted P/Q objects, explicit primitive teacher testimony, direct source evidence, exact candidate witnesses, cloned state fingerprints and corruption/budget tests.

## Limitations and next prerequisites

P selection currently relies on already observed canonical cross-P topology; no previously missing semantic bridge can be invented as a fact. The evaluator's exact typed transitive rule is externally supplied; its semantics have not been learned. Independent child processes, semantic compression, endogenous goal allocation, persistence of a new rule and Council writeback remain out of scope.

Before declaring a genuinely improved cognitive operation, test fresh contexts and paraphrase-invariant evidence, new distractors, different relation families with explicit compositional semantics, and compute/accuracy against a flat canonical graph baseline. No behavioral advantage over a flat approach is demonstrated merely by this operator's correct answer.
