# Frozen terminal-successor repair evaluation v0.65

This increment executes the exact forty-case v0.63 cohort through the exact
private v0.64 adapter. It changes neither frozen input. It publishes the native
responses and later external grades as two separate immutable artifacts so the
response machinery cannot consult expected answers or result labels.

## Durable response-before-grade barrier

The explicitly invoked runner first validates the exact `.vsrp`, `.vsri`,
bound historical artifacts, source checkpoint and 49-file code manifest. It
then prepares four distinct private copies:

| Role | Terminal testimony |
|---|---|
| `taught_repair` | Supplied `18→19→20→21` chain |
| `no_repair_control` | Frozen prompt slots with no successor claims |
| `valid_null` | A distinct copy with the exact supplied chain |
| `wrong_link_control` | Frozen `18→20`, `19→21`, `20→18` chain |

Every copy retains the same twenty-five v0.58 lessons and correct v0.61
operand-order instruction. The response stage receives only each original raw
request plus run/case provenance. It receives no expected answer, external
grade, group label or result-conditioned rule. All 160 records—forty per role,
including eight typed invalid requests per role—are captured and durably saved
before the external grader is called.

Only after the response batch exists does the unchanged v0.58 arithmetic rule
grade the 128 valid **original** requests. Swapped effective requests never
replace the grading target. Invalid cases remain enrolled, retain their raw
typed payload and rejection metadata, and remain visibly ungraded. The full
denominators are therefore forty enrolled and thirty-two valid cases per role.

Reload validates the saved route, original/effective request, order and mapping
lookups, nested addition/counting trace, successor claims/evidence, partial
walks, blocking references, typed errors and external grades without invoking
teaching, response, walking or grading entry points again.

The taught and valid-null arms are exactly equal across every complete native
record apart from the outer role label. The supplied repair adds four correct
responses over no repair, exactly in the prospectively declared
`repair_supported` group:

- `20 + 1` and `1 + 20` use the supplied `20→21` link;
- `19 + 2` and `2 + 19` use `19→20→21`;
- the no-repair arm retains a genuinely missing terminal lookup for all four;
- the wrong-link arm returns `18` for the two `20→18` paths and externally
  grades them incorrect, while the two `19→21` paths stop missing at 21.

All ten pre-boundary controls and six new-domain zero identities are correct in
every role. All twelve declared-domain-ceiling cases abstain in every role:
the correct chain ends at 21 and retains the missing lookup when tokens remain.
Wrong-chain cyclic and missing evidence stays visible. No failed, invalid or
abstained case is replaced, retried, sorted away or removed from a denominator.

This supports a bounded effect of the supplied teacher repair on four frozen
cases. It also falsifies the broader reading that installing those three links
repairs addition generally within this cohort: twelve of thirty-two valid
taught/null requests still have no answer. The correct supported-only value
`20/20` must not replace either `20/32` valid or `20/40` enrolled performance.

correct responses over the matched no-repair control in the predeclared repair
group. The exact null reproduces the complete taught record. The wrong chain
produces two externally incorrect answers and preserves two abstentions. All
twelve ceiling cases continue to abstain. All `140` new evaluation tests,
`1,060` focused math/archive tests and `1,784` full-suite tests
pass, including the existing checks of all seventeen legacy checkpoints.

**IMPLEMENTED-EXPERIMENTAL:** One explicitly invoked four-role private-copy
runner, a complete immutable response-before-grade barrier, a versioned
external grade step, exact static reload, and separate `.vsrb`/`.vsrr`
artifacts bound to the frozen v0.63/v0.64 bytes. The response path uses only
native supplied testimony and retains every success, abstention and rejection.

**PROPOSED:** Before further implementation, freeze one later protocol-only
bounded retention/transfer study. It should first prove that genuinely fresh
disjoint requests remain, then ask whether the exact already-supplied successor
chain can be reused on them with zero new successor lessons against matched
fresh no-repair, exact-null and prospectively wrong-link controls. Teaching
cost, old/private checkpoint lineage, complete native traces and all-response-
before-grade ordering must be declared in advance. Such a study could
characterize narrow reuse only; it must not label retained teacher testimony as
spontaneous discovery or cheaper learning. If no disjoint cases exist within
the frozen 0–21 domain, pause rather than reuse targets or silently widen it.
