abstentions. Their original ordered requests are the four fixed terminal pairs

embedded as `failure_anchors` in the new sidecar.

The future sibling schema is therefore bounded to strict native integers
0 through 21. It declares exactly three new teacher-testimony slots:

| Slot | Proposed correct testimony | Fixed wrong-link testimony |
|---|---|---|
| 1 | 18 → 19 | 18 → 20 |
| 2 | 19 → 20 | 19 → 21 |
| 3 | 20 → 21 | 20 → 18 |

No `21 -> 22` edge is declared. A future walk that reaches 21 with tokens
remaining must retain the missing lookup and abstain. The protocol forbids
integer-derived successor synthesis, numeric token reconstruction and edits to
the v0.57/v0.58/v0.61 types or manifests. Any implementation must use a new
versioned sibling with 0–21 request, answer and step types.
