# ADR-011 — Teaching Inputs Converge on an Editable Explicit Record

**Status:** Accepted  
**Date:** 2026-08-03

## Context

WB-04 initially exposed a deterministic primitive-line compiler and a controlled grammar path. That was useful for verification, but it risked making practical teaching dependent on increasingly complex automatic language parsing.

The Workbench needs to support human authors, pasted output from external LLMs, scripts, imported datasets, deliberate misinformation, contradictory curricula, fictional domains and future provider adapters without giving any one authoring source privileged access to Verdant cognition.

## Decision

The primary Workbench teaching interchange is an **editable explicit teaching record**.

All authoring sources converge on the same representation:

```text
human typing
external LLM copy/paste
provider API
script/import
another researcher
        |
        v
EDITABLE TEACHING RECORD
        |
        v
validator / compiler
        |
        v
frozen .vcurr
        |
        v
Verdant engine
```

A record may contain:

- source sentence/text for provenance;
- explicit concepts;
- explicit relations;
- explicit claims, including negated or mutually contradictory claims;
- context and confidence;
- arbitrary grammar and lexicon annotations for author/reviewer visibility;
- optional executable language scaffold entries that map only to grammar rules and lexical categories already supported by the engine;
- provenance describing who or what authored the material.

The Workbench **does not infer truth or semantic content from the source sentence** in editable-record mode. Source text and annotations are inert provenance unless explicit concepts, relations, claims or supported scaffold entries are supplied.

## Consequences

1. External LLM integration later becomes an authoring convenience rather than a separate teaching architecture.
2. A user can prepare curricula entirely by hand or paste machine-generated records and edit every field before freezing.
3. False, fictional and contradictory information is accepted as experimental input; Workbench validates schema, not reality.
4. Grammar/lexicon knowledge remains distinguishable from world claims.
5. No giant unrestricted English parser is required to make the laboratory usable.
6. The `.vcurr` artifact remains the reproducible boundary: provider/human origin is captured, reviewed, frozen and replayable.
7. Automatic prose decomposition can be added later as an optional producer of editable records without changing Verdant's cognitive substrate.
