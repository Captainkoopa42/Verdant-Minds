# ADR-012 — Forensic Views Are Read-Only Projections of Canonical Records

**Status:** Accepted  
**Milestone:** WB-05 — Structures + Forensic Explorer

## Decision

Verdant Workbench forensic views must be constructed from committed Verdant records and must not infer, repair, or manufacture cognitive events for presentation.

`Replay Formation` is therefore a read-only projection of already-recorded candidate observations, promotion decisions, governance records, evidence references, hierarchy events, availability events, and refolding lineage. Replaying a structure must not advance the engine, mutate canonical state, strengthen associations, create evidence, or change availability.

The initial Explorer topology is likewise forensic rather than generative:

- P nodes come from the promoted structure's recorded member concepts;
- P edges come from the structure's frozen internal edge snapshots;
- Q membership comes from the promoted higher-order record;
- visual layout coordinates are presentation-only and are not treated as cognitive geometry;
- line width, labels, and overlays may visualize recorded measurements but may not invent missing relationships.

## Rationale

The Workbench is intended to function as a laboratory instrument. A researcher must be able to distinguish the system's actual developmental history from UI interpretation. If a replay or graph can silently synthesize plausible events, the Explorer ceases to be usable as evidence.

This decision also preserves the architectural rule established in the Workbench specification:

> Anything the UI claims must be traceable to something the engine actually did.

## Consequences

1. Forensic inspection may expose gaps in current telemetry rather than filling those gaps with presentation logic.
2. `Replay Formation` can be used repeatedly without changing a checkpoint fingerprint or state revision.
3. WB-06 Living Explorer animation must consume the same record/event sources and may only interpolate between recorded states for readability.
4. Any future inferred or model-generated visualization layer must be explicitly labeled as analytical/derived rather than canonical cognitive activity.
