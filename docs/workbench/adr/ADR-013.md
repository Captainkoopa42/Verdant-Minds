# ADR-013 — Living Explorer Is a Read-Only Projection of Recorded Development

**Status:** Accepted  
**Milestone:** WB-06 — Living Explorer

## Context

The Workbench now has enough recorded Verdant history to animate development over time. A visually compelling Explorer creates a serious scientific risk: the presentation layer could accidentally imply cognitive events, geometry, continuity, or causal structure that the engine never recorded.

WB-05 already established that forensic views are read-only projections. WB-06 extends that rule to animation and time-indexed visualization.

## Decision

The Living Explorer is a deterministic, read-only projection of committed Verdant records and measured checkpoint state.

The following rules are mandatory:

1. **Recorded-frame rule.** Cognitive animation may move only between time-indexed frames reconstructed from committed engine records. The frontend may interpolate visually for readability, but it may not invent cognitive events between frames.
2. **No-mutation rule.** Constructing a frame or timeline must not alter canonical Verdant state. Projection code verifies the canonical fingerprint before and after timeline construction.
3. **Live/replay agreement.** The final frame reconstructed from the recorded timeline must have the same projection hash as a direct projection of the live head at the same canonical state.
4. **Presentation-geometry rule.** Canvas coordinates are UI layout only unless an engine record explicitly supplies a cognitive coordinate. Deterministic screen placement must never be described as Verdant's internal geometry.
5. **Record-backed encodings.** Visual encodings must map to recorded measurements: for example, plastic edge width may encode recorded association strength, workspace highlighting may encode admitted workspace bindings, and P boundaries may encode actual promoted membership.
6. **Explicit LOD rule.** Level-of-detail filtering may omit objects for rendering performance, but the frame must report total, rendered, and omitted node/edge counts. Omission must never masquerade as absence from Verdant.
7. **Forensic escape hatch.** Every living frame must expose a frame hash, cycle, event markers, and record-derived details sufficient to return from the visual layer to forensic inspection.

## Consequences

The Explorer is allowed to be visually expressive without becoming an alternate cognitive model. Replay remains reproducible, live and replay views can be checked against one another, and researchers can distinguish recorded cognitive structure from display layout.

This also constrains future visualization work: if a desired animation cannot be justified by a recorded event or measured state transition, it must either be labeled as non-cognitive presentation or not be shown as cognition.
