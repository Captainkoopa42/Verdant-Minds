# ADR-014 — Experiments are immutable verification artifacts

**Status:** Accepted at WB-07

## Decision

Workbench experiments are frozen, content-hashed `.vexp` artifacts. A run consumes the exact frozen manifest, embedded curriculum, resource lock, intervention list, metric list and expected assertions. Editing or changing a parameter creates a new experiment artifact or an explicit fork; it does not rewrite an earlier experiment.

The scientific result hash excludes only declared descriptive/nondeterministic telemetry (currently `training_wall_seconds`). Verification reruns the same frozen protocol and compares this normalized scientific-result hash while separately re-evaluating all declared assertions.

The complete experiment protocol executes outside the Workbench control/UI thread. The current M19 protocol uses four independent kernel/runtime arms inside that experiment worker. The arms share no canonical cognitive state.

## Consequences

- a published `.vexp` can be inspected without trusting presentation text;
- curriculum, seed, state dimension, metrics and interventions are visible before execution;
- a result can be reproduced and hash-compared rather than merely re-plotted;
- experiment forks retain explicit parent lineage;
- timing telemetry remains available but does not make deterministic scientific results appear irreproducible;
- UI result claims are projections of packaged results/assertion checks, not frontend-generated conclusions.
