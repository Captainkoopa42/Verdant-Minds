# V5 examples

This directory currently contains `m14_alien_triad.jsonl`, a small explicit teaching sequence used to exercise Milestone 14 relational-structure cultivation.

The file is input data, not a pretrained model or hidden semantic oracle. Each line should be interpreted through the cultivation/experience contract and preserved with its order when used in a reproduction.

For interactive teaching and structure inspection:

```bash
python run_verdant_cultivation.py
```

For packaged editable curricula and batch sections, use the Workbench Curriculum Studio described in [../docs/workbench/CURRICULUM_PACKS.md](../docs/workbench/CURRICULUM_PACKS.md).

When adding examples, include the intended subsystem, expected record-level outcome, seed/configuration, and explicit non-claims. Avoid examples that depend on evaluator-only labels during native formation.
