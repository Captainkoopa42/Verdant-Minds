# Verdant-Minds Whitepaper

**Title:** Verdant-Minds: A Hybrid Cognitive Architecture with Graph Memory, Wave-State Dynamics, and Measurable Emergent Concept Scaffolding

**Author:** William Adams

**Date:** March 2026

## Files

- `verdant_whitepaper.tex` — LaTeX source. Import into Overleaf with the `figures/` directory to compile.
- `verdant_whitepaper_plaintext.txt` — Plain text version for Zenodo deposit and LLM-readable reference.
- `figures/` — Visualization assets referenced by both versions.

## Compiling

1. Create a new Overleaf project
2. Upload `verdant_whitepaper.tex` as the main document
3. Create a `figures/` folder and upload both PNGs
4. Compile with pdfLaTeX

## Zenodo

Upload the plaintext version alongside the compiled PDF and both figures. Reference the GitHub repo and any prior DOIs.
