# Self-Contained Whitepaper Bundle

This nested directory is a duplicate packaging bundle for the Verdant-Minds whitepaper. It is included so the source, bibliography, plaintext version, figures, and compiled PDF can be transferred or uploaded as one directory.

It does not represent another Verdant branch, another runtime, or a separate set of experimental results.

## Contents

- `verdant_whitepaper.tex` — LaTeX source
- `verdant_whitepaper.bib` — bibliography
- `verdant_whitepaper_plaintext.txt` — plain-text archival copy
- `Verdant_Minds__...pdf` — compiled paper
- `figures/emergent_scaffolding.png` — scaffolding figure
- `figures/link_age_gaps.png` — link-age figure
