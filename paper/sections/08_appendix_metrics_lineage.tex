\section{Appendix: Metrics Lineage}
\subsection{Lineage map}
\begin{itemize}[leftmargin=*]
  \item \textbf{Raw state}: node metadata, timestamps, weighted edges.
  \item \textbf{Derived tables}: emergent nodes, emergent edges, backbone edges.
  \item \textbf{Run-level metrics}: earlier-share, z-scores, concentration metrics.
  \item \textbf{Cross-run aggregates}: mean, std, min/max, success counts ($z>2$).
\end{itemize}

\subsection{Audit notes}
All deterministic transforms are captured by versioned scripts in \texttt{analysis/}. Null-model randomness is controlled by explicit seeds. Output artifacts are emitted as JSON/CSV/PNG to support archive and Zenodo deposition.
